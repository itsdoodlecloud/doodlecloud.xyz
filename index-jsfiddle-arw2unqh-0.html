COMMANDS
______________
DIALOG

-dialog"
  -whatever you type after this command is what the      engine will print
-thinka"
  -whatever you type after this command is what the engine will print in a thought bubble

PEN
-draw(
   -whatever number you type after this is the length of the line the pen will draw
-pendir(
   -puts the pen in a certain direction. this is decided by what number you type in after the command
-pencol(
   -sets the color of the pen to the number you type in after it
   -the default color is red
-penthk(
   -sets the thickness of the pen to the number you type in after it
-erase
   -erases all pen
GET LINES
-get(year
   -prints the current year
-get(month
   -prints the current month
-get(date
   -prints current # day of the month
-get(time
   -prints the time (24hr format)
-daysince00(
   -prints days since 2000
SPRITE MANAGING
(note: there are two sprites, "cat" and "gobo"
-spriteshow(
  -shows a certain sprite
  -this depends on the sprite name you type in after the command
-spritehide(
  -hides a certain sprite
  -this depends on the sprite name you type in after the command
MUSIC
-playnote(
  -plays the note # you type in after it. (hint: #60 is C)
-playdrum(
  -plays the drum # you type in after it
-playtemp(
  -changes music tempo
-setinst(
  -sets the instrument type
-tonerest(
  -rests music
TEXT TO SPEECH
-speaktext(
  -speaks text that you input
-voice(
  -sets the voice type for text to speech
  -the voices are alto, tenor, squeak, giant, and kitten
-lingo(
   -sets your text to speech language
   -the languages are all the ones in the scratch library
GUIDE
